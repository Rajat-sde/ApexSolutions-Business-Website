# ApexSolutions - Multi-Page Business Website 🏢

A responsive, multi-page corporate website designed for modern digital agencies and software solution providers, built using standard HTML5, CSS3, and JavaScript.

---

## 🚀 Features

* **Multi-Page Architecture:** Dedicated navigation across Home, About Us, and Contact pages.
* **Responsive Layout:** Optimized for both mobile devices and large desktop screens using modern CSS Flexbox and Grid.
* **Interactive Contact Form:** Captures user queries with client-side event validation feedback.
* **Clean Corporate Styling:** Minimalist color palette, professional typography, and fixed-top navigation.

---

## 🛠️ Tech Stack

* **HTML5:** Multi-page layout structure (`index.html`, `about.html`, `contact.html`).
* **CSS3:** Global styles, CSS variables, and layout alignment.
* **JavaScript (ES6+):** Form submission feedback handlers.

---
